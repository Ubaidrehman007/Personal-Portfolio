## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/Ubaidrehman007/Personal-Portfolio.git
```

Navigate into the project:

```bash
cd Personal-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
